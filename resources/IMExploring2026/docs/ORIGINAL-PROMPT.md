The prompt asks for a real-time MediaPipe particle simulator where 8,000–15,000 particles form a visitor's face and hands. It specifies:

- a camera opt-in screen and mirrored preview;
- two 21-point hand skeletons;
- a 468-point face mesh;
- tight face clustering and tapered hand-particle spread;
- Rainbow, Fire, Ocean, Galaxy, and Matrix themes;
- a fist gesture to cycle themes;
- attract and repel modes; and
- a smooth, liquid visual feel.

The polished IM Exploring version preserves the immediate walk-up interaction, face/hand landmarks, particles, five named themes, fist gesture, and local browser processing. It adds a full-body pose skeleton, a literal segmentation-based body contour, clearer privacy messaging, adaptive inference, kiosk controls, local vendoring, and explicit error states.

This document summarizes the source prompt; the original text remains preserved in the TechFest directory linked above.
